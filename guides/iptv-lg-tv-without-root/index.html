IPTV on an LG TV, without root.

Your firmware can't be rooted? You can still run homebrew apps with LG's own Developer Mode. Here's how, with TiviBro.

Short answer. Install LG's Developer Mode app from the LG store, sign in with a free LG developer account, and install TiviBro from a computer. The steps for TiviBro are on tivibro.app.

What you need

  • An LG TV on webOS 4 or newer.
  • A free account on LG's webOS TV developer site.
  • A computer on the same network, with webOS Dev Manager or LG's command-line tools.

The steps

Install Developer Mode

Search the LG store for Developer Mode, install it, and sign in with your developer account.

Turn it on

Turn on Dev Mode Status. The TV restarts. Open the app again and turn on Key Server.

Connect from your computer

In webOS Dev Manager, add the TV by its IP address and the passphrase the Developer Mode app shows.

Install TiviBro

Download the latest .ipk from tivibro.app and install it from Dev Manager. It shows up in the TV's app list.

The timer

Developer Mode runs on a timer, shown in its app. Open the app and extend it before it runs out, or apps installed this way stop opening until you do. On a rooted TV there's no timer, and the Homebrew Channel installs and updates TiviBro from the TV: see rooting an LG TV in 2026.

FAQ

Do I need to root my LG TV for an IPTV app?
No. Players in LG's store need nothing. Homebrew apps like TiviBro also install in LG's Developer Mode, without root.
Does Developer Mode expire?
Yes. The Developer Mode app shows a timer, and when it runs out, apps installed that way stop opening until you extend it. On a rooted TV there's no timer.
Is Developer Mode safe?
It's LG's own tool for app developers, from LG's store. It doesn't change the TV's firmware.
