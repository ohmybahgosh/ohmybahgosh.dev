webOS SSH not working?

SSH is how you fix everything else on a rooted TV, so when SSH itself breaks, you need a way in that doesn't use it.

Short answer. Fix it from the TV. SSH Doctor is a Homebrew Channel app that runs as root with just the remote: it turns SSH on, repairs your keys file, sets a password, moves the port safely and resets to defaults.

What the error means

errorusuallyin SSH Doctor

Gone after every restartSSH didn't start at bootFix SSH at startup

Get SSH Doctor without SSH

Open the Homebrew Channel

On the TV, with the remote.

Add the repository

Gear icon, Repositories, Add repository, then https://ohmybahgosh.dev/repo.

Install SSH Doctor

From the app list. Open it and it checks everything on its first screen.

Keep it from breaking again

  • Keep telnet on in the Homebrew Channel, home network only, as a second way in.
  • Turn on Fix SSH at startup.
  • Save or restore my setup puts your keys and the TV's own keys on a USB drive, so a reset doesn't mean starting over.
  • Don't forward the TV's SSH port on your router. SSH Doctor warns if it's open, when the router has UPnP on.

FAQ

How do I fix SSH on a rooted LG TV without SSH?
From the TV. SSH Doctor is a Homebrew Channel app that runs as root with just the remote, so it works when SSH doesn't. Telnet, if you left it on, is the other way in.
SSH stopped working after I added a key.
The first key turns the alpine password off at the next boot. If the key itself is bad, often Windows line endings or a key split over several lines, SSH Doctor's Fix my keys file or Go back to password login gets you back in.
SSH didn't come back after a restart.
Turn on Fix SSH at startup in SSH Doctor. After every restart it checks SSH came up, starts it if not, and fixes keys file permissions the server would refuse.
Why does my computer warn the host key changed?
The TV got new SSH keys, usually after a reset or re-root. Remove the old entry with ssh-keygen -R <TV IP>. SSH Doctor can save the TV's keys to USB so it doesn't happen next time.
