Install Linux packages on an LG TV.

webOS is Linux, but it ships with almost no tools. Entware fills the gap, from a TV app or over SSH.

Short answer. Install Entware from https://ohmybahgosh.dev/repo on a rooted TV. Then browse and install packages from its TV app, or run opkg install htop over SSH.

From the remote

The Entware TV app's Packages screen lists every package by category, with a one-line description, its size, what else it pulls in and the free space left. Start here has the popular ones: htop, mc, rclone, ncdu, tmux, aria2, fzf, zsh, ffmpeg, yt-dlp, micro and nmap.

Over SSH

$ opkg update
$ opkg list | grep -i python
$ opkg install htop tmux git

Entware also adds ent, a helper for searching and checking packages with Tab completion, and a bash shell. opkg itself is Entware's own, untouched.

32-bit or 64-bit

Every LG TV runs 32-bit apps, but Entware brings its own libraries, so only the kernel matters. The installer checks and picks the faster 64-bit build when the kernel is 64-bit, after a test run on the TV.

Add-ons, set up for you

Some packages need more than an install to work on webOS. Entware's 25 add-ons do that part: Tailscale, Samba, File Browser, a DLNA server, Transmission, Syncthing, Python, git and more.

FAQ

Can I install Linux packages on an LG TV?
On a rooted TV, yes. Entware adds opkg and over 1,100 packages, installed to the TV's app storage.
Does it fill up the TV?
Entware itself is about 50 MB. The TV app shows each package's size and the free space before you install.
Does it survive a reboot?
Yes. A Homebrew Channel boot script mounts it at every start.
