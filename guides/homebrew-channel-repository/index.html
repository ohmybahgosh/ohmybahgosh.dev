Add a repository to the Homebrew Channel.

Repositories are how apps that aren't in the default list get onto a rooted LG TV, and how they update from the TV.

Steps

Open the settings

Open the Homebrew Channel on the TV and select the gear icon at the top right.

Add the repository

Scroll to Repositories and choose Add repository. Type the address, for example https://ohmybahgosh.dev/repo, and confirm.

Find the apps

Go back to the app list. The repository's apps are listed with the rest: open one and choose Install.

Updates

New versions show up as an update on the app's page in the Homebrew Channel.

Typing it with the remote

The on-screen keyboard is slow, so type carefully: https:// included, no trailing spaces. If the app list doesn't change, check the TV is online and the address has no typos, then reopen the Homebrew Channel.

Prefer the command line?

Every app here can also be installed over SSH: see each app's page. TiviBro, for example, installs with one line on a rooted TV:

$ curl -fsSL https://tivibro.app/install | sh

FAQ

What is a Homebrew Channel repository?
A web address that serves a list of apps with their versions and download links. The Homebrew Channel reads it, shows those apps in its list, and offers updates when the list changes.
Is it safe to add a repository?
Apps from it run as root, so only add ones you trust. Every app in ohmybahgosh.dev/repo is open source, built from its GitHub releases, and checked by SHA-256 when it downloads.
Which apps does ohmybahgosh.dev/repo add?
TiviBro, LG-USB-2-ETH0, Entware and SSH Doctor.
How do I remove a repository?
In the Homebrew Channel's settings, under Repositories, select it and remove it. Apps you already installed stay installed.
