Check your LG TV firmware version.

Whether a TV can be rooted comes down to this one number. Here's where to find it, and what to do with it.

Short answer. Settings, then Support, then Software Update. Check that version at cani.rootmy.tv. If it can be rooted, keep it that way: block updates first, and turn on FW Block once rooted.

Find it

Open Settings

Press the gear button on the remote, then All settings.

Go to Support

Then Software Update, or TV Information on some models.

Write down the version

It looks like 33.22.65. TV Information also shows the model number and webOS version.

Before you look: block updates

Opening the Software Update page can start a check, and a TV with automatic updates on may install what it finds. If your firmware might be rootable, add LG's update servers to your router's blocklist first. The list is in Block LG TV firmware updates.

Can it be rooted?

Enter the version at cani.rootmy.tv. webOS 26 builds from before October 10, 2026 still root, and later ones don't: rooting an LG TV in 2026 has the details by model.

FAQ

Where do I find my LG TV's firmware version?
Settings, then Support, then Software Update. The version is at the top, like 33.22.65.
What's the difference between the webOS version and the firmware version?
webOS is the platform, like webOS 24. The firmware version is the exact build on top of it, and that's what decides whether a TV can be rooted.
Will checking for updates install one?
Opening the Software Update page can start a check. If you want to keep your current firmware, block updates on your router first.
