Syncthing on an LG TV.

Drop a video in a folder on your computer, and it's on the TV. No cloud, no USB stick.

Short answer. On a rooted TV, install Entware and press Syncthing in its Add-ons. Its web page is at http://<TV IP>:8384, user tv, and it syncs /opt/files/Sync.

Set it up

Add Syncthing

In the Entware TV app, open Add-ons and press Syncthing. It makes a password on the TV before it first starts.

Open its web page

From your computer or phone, go to http://<TV IP>:8384 and log in as tv. The TV app shows the password and a QR code.

Pair your devices

Add your computer or phone by its device ID, the usual Syncthing way, and share a folder with the TV.

Watch it

Synced videos land in /opt/files/Sync. Play them on other devices with the DLNA add-on, or grab them with File Browser.

Pairs well with

  • Tailscale, to sync from away from home.
  • Samba and File Browser, for files you copy by hand.

FAQ

Can I run Syncthing on an LG TV?
On a rooted TV, yes. It's an Entware add-on, set up with a password before it first starts.
Which folder does it sync?
/opt/files/Sync by default. Add more from its web page.
Does it sync while the TV is off?
Count on it only while the TV is on. Changes catch up the next time it is.
