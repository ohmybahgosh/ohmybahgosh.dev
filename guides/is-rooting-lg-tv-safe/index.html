Is rooting an LG TV safe?

Mostly, if you treat the TV like the Linux computer it is. Here are the risks that matter and the ones that don't.

Short answer. For most people, yes. The real risks are an update taking root away and SSH left open with the default password. FW Block handles the first, and SSH Doctor sets up a key, a new password and warns if your router forwards SSH to the internet.

The real risks

riskwhat to do
An update removes root for goodBlock updates as soon as you root. FW Block.
SSH or telnet on the default passwordSet up a key, change the password. SSH Doctor.
SSH open to the internetNo port forwards to the TV. SSH Doctor checks the router for them.
A command run as root that breaks somethingCopy commands only from sources you trust, and read them first.

The overblown ones

  • Bricking. The common rooting tools don't rewrite the firmware. Bricks come from flashing things, not from rooting.
  • Losing LG's apps. Netflix, YouTube and the store keep working on a rooted TV.

A safe setup in four steps

Block updates

FW Block, right after rooting.

Lock down SSH

SSH Doctor: a key, your own password, no port forwards.

Keep telnet on, but home only

It's your way back in if SSH ever breaks.

Install from sources you trust

Like the Homebrew Channel's default list and https://ohmybahgosh.dev/repo.

FAQ

Can rooting brick my LG TV?
The common rooting tools don't touch the firmware itself, and a bricked TV from rooting alone is rare. Running commands as root without knowing what they do is the bigger risk.
Does rooting void the warranty?
That's between you and LG, and it can vary by country. Rooting is done at your own risk.
Is a rooted TV less secure?
It can be, if SSH or telnet is open to the internet or still on the default password. Keep them on your home network only, and use a key.
