Will a firmware update remove root?

Short version: usually, and you can't go back. Here's what breaks, what keeps working, and how to make sure it doesn't happen.

Short answer. Usually yes, and patched firmware can't be rooted again. Turn on FW Block as soon as your TV is rooted: one switch blocks the update check, every LG update server, Remote Support and phone app updates.

Why updates remove root

Rooting tools use security holes in LG's software. Updates close them, and a fresh firmware image wipes the changes that gave you root. Since LG doesn't offer downgrades, a TV that updates to patched firmware stays that way.

What breaks

appafter an update that removes root
TiviBroKeeps working. It doesn't need root.
LG-USB-2-ETH0Stops. The TV goes back to the built-in port.
EntwareStops, with every add-on.
SSH DoctorStops, and so does SSH as root.

How updates slip through

  • Turning off automatic updates in settings doesn't stop every check.
  • The Homebrew Channel's Block system updates covers four servers. The updater knows seven, plus one IP address.
  • LG Remote Support and paired phone apps can push an update past server blocks.

FW Block closes all of them and checks every 10 minutes. If you already run LG-USB-2-ETH0, its Block updates harder does the same. The details are in Block LG TV firmware updates.

FAQ

Will a firmware update remove root on my LG TV?
Usually, yes. Updates patch the holes rooting tools use, and once a TV is on patched firmware there's no known way to root it again.
What happens to my homebrew apps after an update?
Apps that don't need root, like TiviBro, keep working. Apps that need root, like LG-USB-2-ETH0, Entware and SSH Doctor, stop working until the TV is rooted again, which may not be possible.
Can I roll back LG firmware?
Not in any normal way. LG doesn't offer downgrades, so blocking updates beforehand is the only real protection.
