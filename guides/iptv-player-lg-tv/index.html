Looking for TiviMate on an LG TV?

TiviMate is Android-only, so it won't install on webOS. TiviBro is a free, open-source IPTV player built for LG TVs, with the same guide-first layout.

TiviBro's home is tivibro.app. Install steps, the full feature list, the Android phone app and the user guide are all there. This page is the short version.

What it does

  • Guide first. Live preview top left, details top right, groups one press away. OK previews, OK again goes fullscreen.
  • Your own subscription. An Xtream Codes IPTV login, or an M3U playlist with an XMLTV guide. Paste your provider's whole link and it fills in the rest.
  • Set up from your phone. Scan the QR code on the first screen and type your login with a real keyboard.
  • Catch-up, movies and shows, search. Rewind the guide, your provider's VOD with posters and resume, and one search across everything.
  • Sports and PPV, readable. Events crammed into channel names show with the game in the guide at its real time. My teams gathers your teams' games from every channel.
  • A web editor and an Android app. Clean up thousands of channels from any browser, with drafts and undo. The phone app is a remote that can also play channels on the TV and turn it on.

Install

On a rooted TV, add https://tivibro.app/repo (or https://ohmybahgosh.dev/repo) to the Homebrew Channel and install it from the app list. Without root, use LG's Developer Mode. Both are covered on tivibro.app.

FAQ

Is TiviMate available on LG TVs?
No. TiviMate is an Android app, for Android TV and Fire TV. LG TVs run webOS, so it doesn't install there.
What is TiviBro?
A free, open-source IPTV player for LG webOS TVs, built in the style of TiviMate: the guide is the home screen. It plays your own Xtream Codes or M3U subscription. It doesn't come with channels.
Do I need a rooted TV for TiviBro?
No. It installs in LG's Developer Mode too. On a rooted TV, the Homebrew Channel installs and updates it from the TV.
Is TiviBro free?
Yes, every feature, MIT licensed, with no account, ads or tracking. It counts installs by version once a day, anonymously, and that can be switched off.
Which LG TVs does TiviBro run on?
webOS 4 and newer. It's tested every day on real TVs from a 2019 webOS 4 OLED to webOS 25. It's in alpha testing, so expect some rough edges.
