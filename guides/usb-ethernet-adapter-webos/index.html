A USB Ethernet adapter on webOS, as the main connection.

Plug one into an LG TV and it usually lights up, then does nothing useful. Here's why, and how to make it the TV's real wired connection.

Short answer. webOS names a USB adapter eth1 and only treats eth0 as the wired connection. On a rooted TV, install LG-USB-2-ETH0 from https://ohmybahgosh.dev/repo: it makes the adapter eth0, and settings and apps use it at about 250 to 330 Mbit/s.

Why webOS ignores the adapter

  • "Not Connected." Settings only look at eth0, the built-in port, so a working adapter shows as no wired connection.
  • Apps refuse it. Some, like Paramount+, won't play over eth1.
  • No driver. Some kernels have no driver for the adapter's chip, or only the slower generic cdc_ncm.

Set it up

Root the TV

With the Homebrew Channel. Check your firmware at cani.rootmy.tv and follow the install guide.

Stay on Wi-Fi while you set up

The switch takes the wired ports down for a moment.

Add the repository

In the Homebrew Channel, select the gear icon, then Repositories, Add repository, and enter https://ohmybahgosh.dev/repo.

Install LG-USB-2-ETH0

Open it from the app list and choose Install.

Plug in the adapter and turn it on

The app makes the adapter eth0 and parks the built-in port as eth2. Settings show the wired connection.

Prefer SSH?

$ sh LG-USB-2-ETH0.sh status
$ sh LG-USB-2-ETH0.sh install --now

status is a read-only look first. The full download and checksum steps are on the LG-USB-2-ETH0 page.

Which adapter

A gigabit adapter with a Realtek RTL8153 or ASIX AX88179 chip is the safe pick. More in which USB Ethernet adapter for an LG TV.

FAQ

Does webOS support USB Ethernet adapters?
Partly. Many LG kernels have drivers for common chips, so the adapter comes up, but as eth1. webOS settings and many apps only use eth0, so the TV acts like it isn't there.
Do I need root to use a USB Ethernet adapter on an LG TV?
To make it the TV's real wired connection, yes. Without root, webOS leaves it as a second interface its settings don't show.
My adapter isn't detected at all.
Your TV's kernel may have no driver for its chip. LG removed the Realtek driver from 2024 QNED and OLED models, for one. LG-USB-2-ETH0's Faster driver fetches one built for your exact kernel when one is known.
Can I undo it?
Yes. Turn everything off in the app gives eth0 back to the built-in port and removes its boot hook. No system files are touched.
