LG-USB-2-ETH0 makes a USB Ethernet adapter the TV's eth0, so webOS settings and streaming apps use the faster wired link instead of the 100 Mbit/s built-in port.

The app shows which adapter and driver the TV sees, switches the adapter in or back, installs the boot hook so it happens at every start, runs a speed test, and checks for updates.

Needs a rooted TV with the Homebrew Channel. Set up Wi-Fi first: switching takes the wired ports down for a moment. Everything it changes can be undone from the app.

Guide, compatibility list and support: ohmybahgosh.dev/lg-usb-2-eth0
