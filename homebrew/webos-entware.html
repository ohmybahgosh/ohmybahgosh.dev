Entware

Entware brings hundreds of Linux command line packages to your TV through opkg: git, Python, htop, tmux, rsync and many more. This app installs and manages it from the remote, so you don't need SSH to set it up. It runs the same installer as the command-line version, as root through the Homebrew Channel.

In the app

  • Status at a glance: whether Entware is installed and mounted, the build, packages and disk use, where it lives, the free space on both storage areas, the boot script, the SSH shell, nano, HTTPS certificates, locate and telnet recovery, plus any problems found.
  • Install Entware, or Repair when something's wrong. It picks the recommended build for your TV and keeps your packages and settings on a repair.
  • Add-ons: nano with syntax colors, locate, HTTPS certificates, git, Python, htop, tmux, ncdu, rsync, curl, jq and a login banner, each with the setup it needs on webOS. One press adds, finishes setting up or removes one.
  • Login banner: an add-on that shows a webOS wordmark and your TV's specs each time you log in over SSH. It downloads neofetch 7.1.0 from GitHub and only uses it if it matches the release's checksum. touch ~/.hushlogin hides it.
  • Packages: every package that's installed, with its version and size and Remove. The search field opens the TV's keyboard: type a word like htop or python, and Install any of the 2,900+ Entware packages that match, with the same webOS setup ent install does. Packages Entware needs, and ones other packages need, say why they stay.
  • Package updates: every package with an update, with its current and new version. Update one or Update all. The button says how many there are, and the app checks for new ones once a day.
  • Live progress: every task runs in the background on the TV. Closing the app doesn't stop it, and reopening the app picks the progress back up.
  • Full check and logs: everything doctor looks at, on screen, plus this boot's log from the boot script and the logs of the last 10 tasks the app ran.
  • Report for GitHub: a QR code that opens a report on your phone with your TV, version, build and the full check already filled in. It works on my TV opens a compatibility report, and Something went wrong a bug report.
  • Updates itself: when a new version is out, Update to v… downloads it from GitHub, checks it against the release's SHA256SUMS, installs it and reopens. The Homebrew Channel offers the same updates.
  • What's new: after the app updates, it shows what changed, once.

Careful by default

  • Checks your TV first: root, model, webOS version, kernel, free space and the Entware download server.
  • Recommends the 64-bit or 32-bit build from your kernel and test-runs it before anything is kept. If 64-bit can't run, it falls back to 32-bit.
  • Installs on the TV's app storage, which has room to spare and keeps Entware through "Reset to initial settings". Older installs on user data move over with a checked move on their next repair, or with Move to app storage. You can keep it on user data instead.
  • Only uses an Entware folder that's root's alone, and adds one Homebrew Channel boot script. System partitions are never touched.
  • A failed install undoes itself, and your own shell files are backed up and put back.
  • Uninstall Entware in the app takes it all back out. Removing the app alone leaves Entware installed.

Already using it over SSH?

Open the app and it shows your install as it is. The app and the webos-entware command run the same installer, so you can switch between them any time.
