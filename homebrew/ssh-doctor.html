Needs a rooted TV with the Homebrew Channel. It runs as root through the Homebrew Channel, not over SSH, so it works even when SSH is completely broken.

SSH Doctor

SSH on a rooted LG TV is easy to break and hard to fix: a key pasted from Windows, a private key pasted instead of the public one, a keys file that turned the alpine password off, or SSH turned on in the Homebrew Channel but never started. This app finds out what's wrong and fixes it with the remote.

The check

  • Whether SSH is on in the Homebrew Channel, and whether its server is running on its port.
  • Every SSH server on the TV: the Homebrew Channel's, Entware's, Developer Mode's, or something else on the SSH port.
  • How you can log in: the alpine password, your keys, or nobody.
  • Whether authorized_keys is usable: Windows line endings, hidden characters, keys split over several lines, PuTTY's key format, private keys, and permissions.
  • Telnet as a way back in, failsafe mode, the TV's address, and its SSH key fingerprints.

Fixes, one button each

  • Turn SSH on now, without the restart the Homebrew Channel needs.
  • Fix my keys file: repairs it and moves anything that isn't a public key to a side file.
  • Go back to password login, for anyone locked out: user root, password alpine.
  • Undo a change: every fix keeps a backup first.

SSH settings, kept after a restart

  • Your own password, typed on the TV or on your phone. Only a scrambled hash is ever sent or kept.
  • Keys only, which won't turn on until a key is on the TV.
  • SSH port: the old port stays open until you've logged in on the new one and keep it.
  • Keep idle sessions connected, and Reset to Homebrew Channel defaults.

More tools

  • Rename or remove keys, and see when each last logged in.
  • Login history with failed tries, telnet off or on, SFTP details, the TV's own SSH keys, and a report for getting help with no private details in it.

Set up a key with a pairing code

The TV shows a QR code, its address and a short code. Open the page on your phone or computer, type the code, and send the public key you have, or let the browser make a new key pair: the private key is saved on your device and never sent anywhere. The key is added only after you press OK on the remote, and the page then shows the exact command for Mac, Linux, Windows, PuTTY or a phone app.
