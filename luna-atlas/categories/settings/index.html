Documented methods to start with

Public and SSAP methods from LG's documentation, none flagged dangerous. Each opens in the catalog with its full parameter table. Run them on a rooted TV or in Developer Mode.

dump publiccom.webos.service.config

It is useful for debugging. It returns the list of all configs and current values.

$ luna-send -n 1 -f luna://com.webos.service.config/dump '{}'
fullDump publiccom.webos.service.config

It is useful for debugging. It returns the list of all configs including overridden values from all layers.

$ luna-send -n 1 -f luna://com.webos.service.config/fullDump '{}'
getConfigs publiccom.webos.service.config

It returns the requested configs which is the pairs of key-value as a JSON object and also supports a subscription. configd provides asterisk but configNames should starts feature

params: configNames, subscribe

$ luna-send -n 1 -f luna://com.webos.service.config/getConfigs '{}'
reconfigure publiccom.webos.service.config

Configd parses all configuration files again and regenerates the values of configs .

$ luna-send -n 1 -f luna://com.webos.service.config/reconfigure '{}'
reloadConfigs publiccom.webos.service.config

Configd load configd db files. This load previous config values including user defined configs(by calling setConfigs)

$ luna-send -n 1 -f luna://com.webos.service.config/reloadConfigs '{}'
