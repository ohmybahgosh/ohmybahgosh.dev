Documented methods to start with

Public and SSAP methods from LG's documentation, none flagged dangerous. Each opens in the catalog with its full parameter table. Run them on a rooted TV or in Developer Mode.

setMuted publiccom.webos.audio

Mutes or unmutes the volume.

params: muted

$ luna-send -n 1 -f luna://com.webos.audio/setMuted '{}'
volumeDown publiccom.webos.audio

Decreases the volume by 1.

$ luna-send -n 1 -f luna://com.webos.audio/volumeDown '{}'
volumeUp publiccom.webos.audio

Increases the volume by 1.

$ luna-send -n 1 -f luna://com.webos.audio/volumeUp '{}'
audio/changeSoundOutput ssapcom.webos.service.apiadapter

Change sound output

params: output

$ luna-send -n 1 -f luna://com.webos.service.apiadapter/audio/changeSoundOutput '{}'

registerTrack publiccom.webos.service.audio

Registers a playback by an application/service and returns a track ID. The track ID must be used to control the volume of that particular playback by using setTrackVolume() .

params: streamType

$ luna-send -n 1 -f luna://com.webos.service.audio/registerTrack '{}'
Before you run anything. Methods marked dangerous can change, reset or break things on the TV. Running one from here is exactly as safe as typing the same luna-send yourself. See dangerous.md.
