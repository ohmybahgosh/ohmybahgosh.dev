Documented methods to start with

Public and SSAP methods from LG's documentation, none flagged dangerous. Each opens in the catalog with its full parameter table. Run them on a rooted TV or in Developer Mode.

audio/connect publiccom.webos.service.avoutput

Connects audio source to audio sink. Note : In case it's already connected, will disconnect from previous sink automatically.

params: source, sourcePort, sink, outputMode, audioType

$ luna-send -n 1 -f luna://com.webos.service.avoutput/audio/connect '{}'
audio/disconnect publiccom.webos.service.avoutput

Disconnect from audio sink. No change is done if not connected.

params: source, sourcePort, sink

$ luna-send -n 1 -f luna://com.webos.service.avoutput/audio/disconnect '{}'
audio/getStatus publiccom.webos.service.avoutput

Lists all video and audio sinks and their status.

params: subscribe

$ luna-send -n 1 -f luna://com.webos.service.avoutput/audio/getStatus '{}'
audio/mute publiccom.webos.service.avoutput

Stop/start outputting data to audio sink. This allows seamless disconnect and connect and avoids outputting invalid data while reconnection is in progress.

params: Source, sourcePort, sink, mute

$ luna-send -n 1 -f luna://com.webos.service.avoutput/audio/mute '{}'
audio/volume/down publiccom.webos.service.avoutput

Decreases the volume.

params: tvSoundOutput

$ luna-send -n 1 -f luna://com.webos.service.avoutput/audio/volume/down '{}'
audio/volume/set publiccom.webos.service.avoutput

Set volume to a numerical value.

params: volume, tvSoundOutput

$ luna-send -n 1 -f luna://com.webos.service.avoutput/audio/volume/set '{}'
audio/volume/up publiccom.webos.service.avoutput

Increases the volume.

params: tvSoundOutput

$ luna-send -n 1 -f luna://com.webos.service.avoutput/audio/volume/up '{}'
