Documented methods to start with

Public and SSAP methods from LG's documentation, none flagged dangerous. Each opens in the catalog with its full parameter table. Run them on a rooted TV or in Developer Mode.

getResponse publiccom.webos.service.ai.voice

Returns speech recognition results. This method is asynchronous.

params: subscribe

$ luna-send -n 1 -f luna://com.webos.service.ai.voice/getResponse '{}'
getState publiccom.webos.service.ai.voice

Gets the current state of the service. It can have the following states: idle : Before start. waitActivation : Wait for keyword activation. recording : Uploading audio to the serve

params: subscribe

$ luna-send -n 1 -f luna://com.webos.service.ai.voice/getState '{}'
start publiccom.webos.service.ai.voice

Starts the service based on the mode selected. Note: This method is only for allowed clients.

params: mode, keywordDetect

$ luna-send -n 1 -f luna://com.webos.service.ai.voice/start '{}'
stop publiccom.webos.service.ai.voice

Stops the service. Make sure to call this method before starting another engine. Note: This method is only for allowed clients.

$ luna-send -n 1 -f luna://com.webos.service.ai.voice/stop '{}'
