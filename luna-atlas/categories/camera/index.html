Documented methods to start with

Public and SSAP methods from LG's documentation, none flagged dangerous. Each opens in the catalog with its full parameter table. Run them on a rooted TV or in Developer Mode.

setWindow publiccom.webos.pipeline.camera

Sets the window's position and size, display ID, and overlay/mirror options.

params: x, y, w, h, displayId, overlay, mirror

$ luna-send -n 1 -f luna://com.webos.pipeline.camera/setWindow '{}'
start publiccom.webos.pipeline.camera

Starts the preview.

params: appId, windowId, videoDisplayMode, width, height, format, frameRate, memType

$ luna-send -n 1 -f luna://com.webos.pipeline.camera/start '{}'
stop publiccom.webos.pipeline.camera

Stops the preview.

$ luna-send -n 1 -f luna://com.webos.pipeline.camera/stop '{}'
