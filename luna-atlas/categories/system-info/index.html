Documented methods to start with

Public and SSAP methods from LG's documentation, none flagged dangerous. Each opens in the catalog with its full parameter table. Run them on a rooted TV or in Developer Mode.

osInfo/query publiccom.palm.systemservice

Returns OS info keys such as webos_release, webos_manufacturing_version, device_name

params: parameters, subscribe

$ luna-send -n 1 -f luna://com.palm.systemservice/osInfo/query '{}'
time/getSystemTime publiccom.palm.systemservice

Returns the system time; subscribable for timezone or >5 min time changes.

params: subscribe

$ luna-send -n 1 -f luna://com.palm.systemservice/time/getSystemTime '{}'
