Documented methods to start with

Public and SSAP methods from LG's documentation, none flagged dangerous. Each opens in the catalog with its full parameter table. Run them on a rooted TV or in Developer Mode.

subscribeToCommands\ publiccom.palm.service.tellurium

\ Subscribes to Tellurium commands\ \

params: ---, subscribe, appInfo, baseURI, width, height, name, scene

$ luna-send -n 1 -f luna://com.palm.service.tellurium/subscribeToCommands\ '{}'
subscribeToEvents\ publiccom.palm.service.tellurium

\ Subscribes to stages' events (received from stage in notifyEvent)\ \

params: ---, subscribe

$ luna-send -n 1 -f luna://com.palm.service.tellurium/subscribeToEvents\ '{}'
version\ publiccom.palm.service.tellurium

\ Returns the tellurium version from the submission tag.\ \

$ luna-send -n 1 -f luna://com.palm.service.tellurium/version\ '{}'
