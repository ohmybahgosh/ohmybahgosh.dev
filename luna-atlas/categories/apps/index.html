Documented methods to start with

Public and SSAP methods from LG's documentation, none flagged dangerous. Each opens in the catalog with its full parameter table. Run them on a rooted TV or in Developer Mode.

close ssapcom.webos.applicationManager

Close an app by id (SSAP)

params: id

$ luna-send -n 1 -f luna://com.webos.applicationManager/close '{}'
closeByAppId publiccom.webos.applicationManager

Closes a running app by id

params: id

$ luna-send -n 1 -f luna://com.webos.applicationManager/closeByAppId '{}'
dev/closeByAppId publiccom.webos.applicationManager

Developer-mode variant of closeByAppId used by ares-launch to close a dev app

params: id, subscribe

$ luna-send -n 1 -f luna://com.webos.applicationManager/dev/closeByAppId '{}'
dev/listApps publiccom.webos.applicationManager

Lists developer-mode (and dev-visible) apps with id, version, folderPath, icon

$ luna-send -n 1 -f luna://com.webos.applicationManager/dev/listApps '{}'
dev/running publiccom.webos.applicationManager

Developer-mode listing of running apps (ares-launch --running)

$ luna-send -n 1 -f luna://com.webos.applicationManager/dev/running '{}'
getAppInfo ssapcom.webos.applicationManager

Get info for one installed app

params: id

$ luna-send -n 1 -f luna://com.webos.applicationManager/getAppInfo '{}'
