Documented methods to start with

Public and SSAP methods from LG's documentation, none flagged dangerous. Each opens in the catalog with its full parameter table. Run them on a rooted TV or in Developer Mode.

channelDown ssapssap:tv

Channel down

$ luna-send -n 1 -f ssap://tv/channelDown '{}'
channelUp ssapssap:tv

Channel up

$ luna-send -n 1 -f ssap://tv/channelUp '{}'
getChannelCurrentProgramInfo ssapssap:tv

Get currently airing program info

params: channelId

$ luna-send -n 1 -f ssap://tv/getChannelCurrentProgramInfo '{}'
getChannelList ssapssap:tv

List tuned channels

params: subscribe

$ luna-send -n 1 -f ssap://tv/getChannelList '{}'
getChannelProgramInfo ssapssap:tv

Get program (EPG) info for a channel

params: channelId

$ luna-send -n 1 -f ssap://tv/getChannelProgramInfo '{}'
getCurrentChannel ssapssap:tv

Get/subscribe current channel

params: subscribe

$ luna-send -n 1 -f ssap://tv/getCurrentChannel '{}'
openChannel ssapssap:tv

Tune a channel

params: channelId, channelNumber

$ luna-send -n 1 -f ssap://tv/openChannel '{}'
Before you run anything. Methods marked dangerous can change, reset or break things on the TV. Running one from here is exactly as safe as typing the same luna-send yourself. See dangerous.md.
