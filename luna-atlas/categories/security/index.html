Documented methods to start with

Public and SSAP methods from LG's documentation, none flagged dangerous. Each opens in the catalog with its full parameter table. Run them on a rooted TV or in Developer Mode.

getRightsError publiccom.webos.service.drm

Returns DRM rights error info on license errors during playback.

params: clientId, subscribe

$ luna-send -n 1 -f luna://com.webos.service.drm/getRightsError '{}'
abort publiccom.webos.service.keymanager3

Aborts an in-progress operation.

params: handle

$ luna-send -n 1 -f luna://com.webos.service.keymanager3/abort '{}'
begin publiccom.webos.service.keymanager3

Starts a crypto operation and returns a handle.

params: name, params

$ luna-send -n 1 -f luna://com.webos.service.keymanager3/begin '{}'
exportKey publiccom.webos.service.keymanager3

Gets the public key of a key pair.

params: name

$ luna-send -n 1 -f luna://com.webos.service.keymanager3/exportKey '{}'
finish publiccom.webos.service.keymanager3

Completes the operation and returns result.

params: handle, data

$ luna-send -n 1 -f luna://com.webos.service.keymanager3/finish '{}'
generateKey publiccom.webos.service.keymanager3

Generates a key for algorithms supported by keymanager3.

params: name, params

$ luna-send -n 1 -f luna://com.webos.service.keymanager3/generateKey '{}'
importKey publiccom.webos.service.keymanager3

Imports an externally generated key.

params: name, data, params

$ luna-send -n 1 -f luna://com.webos.service.keymanager3/importKey '{}'
removeKey publiccom.webos.service.keymanager3

Deletes a key.

params: name

$ luna-send -n 1 -f luna://com.webos.service.keymanager3/removeKey '{}'
update publiccom.webos.service.keymanager3

Feeds data to an operation handle.

params: handle, data

$ luna-send -n 1 -f luna://com.webos.service.keymanager3/update '{}'
deviceid/getIDs publiccom.webos.service.sm

Returns device IDs provided by webOS TV (LGUDID).

params: idType

$ luna-send -n 1 -f luna://com.webos.service.sm/deviceid/getIDs '{}'
setPin ssapssap:pairing

Submit PIN during PIN-type pairing

params: pin

$ luna-send -n 1 -f ssap://pairing/setPin '{}'
getACRAuthToken ssapssap:tv

Get ACR auth token

$ luna-send -n 1 -f ssap://tv/getACRAuthToken '{}'
Before you run anything. Methods marked dangerous can change, reset or break things on the TV. Running one from here is exactly as safe as typing the same luna-send yourself. See dangerous.md.
