Documented methods to start with

Public and SSAP methods from LG's documentation, none flagged dangerous. Each opens in the catalog with its full parameter table. Run them on a rooted TV or in Developer Mode.

closeAlert publiccom.webos.notification

Closes the currently displayed alert notification.

params: alertId

$ luna-send -n 1 -f luna://com.webos.notification/closeAlert '{}'
closeAllAlerts publiccom.webos.notification

Closes all the open alerts. Note: This method is for internal use. It must only be used by com.webos.service.battest during BAT test . If the caller is not com.webos.service.battes

$ luna-send -n 1 -f luna://com.webos.notification/closeAllAlerts '{}'
closeToast publiccom.webos.notification

Removes a toast notification from the database.

params: toastId, sourceId

$ luna-send -n 1 -f luna://com.webos.notification/closeToast '{}'
createAlert publiccom.webos.notification

Creates a system alert notification.

params: iconUrl, title, message, modal, buttons, onclose, type, isSysReq

$ luna-send -n 1 -f luna://com.webos.notification/createAlert '{}'
createToast publiccom.webos.notification

Creates a toast notification.

params: sourceId, iconUrl, message, onclick, noaction, stale, persistent, isSysReq

$ luna-send -n 1 -f luna://com.webos.notification/createToast '{}'
disable publiccom.webos.notification

Disables all notification features (Toast, Alert, Input Alert, Pin Prompt). Note: Only a privileged application or service can call this method.

$ luna-send -n 1 -f luna://com.webos.notification/disable '{}'
enable publiccom.webos.notification

Enables all notification features (Toast, Alert, Input Alert, Pin Prompt). Note: Only a privileged app/service can call this method.

$ luna-send -n 1 -f luna://com.webos.notification/enable '{}'
getAlertNotification publiccom.webos.notification

Subscribe to create alert notifications. Note: This method should only be used by the Surface Manager .

params: subscribe

$ luna-send -n 1 -f luna://com.webos.notification/getAlertNotification '{}'
getToastCount publiccom.webos.notification

Queries the toast notification details of the stored messages and provides the read/unread count of the toast notifications. Note: Only "com.webos.surfacemanager" and "com.webos.ap

params: subscribe, displayId

$ luna-send -n 1 -f luna://com.webos.notification/getToastCount '{}'
getToastList publiccom.webos.notification

Lists the toasts created for the app/client based on the user logged into the particular session.

params: displayId

$ luna-send -n 1 -f luna://com.webos.notification/getToastList '{}'
getToastNotification publiccom.webos.notification

Subscribe to created toast notification. Note: This method should only be used by Surface Manager only.

params: subscribe

$ luna-send -n 1 -f luna://com.webos.notification/getToastNotification '{}'
removeAllNotification publiccom.webos.notification

Removes all notifications that are currently being displayed.

params: displayId

$ luna-send -n 1 -f luna://com.webos.notification/removeAllNotification '{}'
removeNotification publiccom.webos.notification

Deletes the given notification(s) from DB. We can remove given set of notifications or remove all notifications from a given sourceId.

params: removeNotiId, sourceId

$ luna-send -n 1 -f luna://com.webos.notification/removeNotification '{}'
setToastStatus publiccom.webos.notification

Specifies whether the toast is to be marked as read or unread.

params: toastId, readStatus

$ luna-send -n 1 -f luna://com.webos.notification/setToastStatus '{}'
closeAlert ssapssap:system.notifications

Close an alert (required after the createAlert luna trick so the alert does not stay on screen)

params: alertId

$ luna-send -n 1 -f ssap://system.notifications/closeAlert '{}'
closeToast ssapssap:system.notifications

Close a toast

params: toastId

Before you run anything. Methods marked dangerous can change, reset or break things on the TV. Running one from here is exactly as safe as typing the same luna-send yourself. See dangerous.md.
