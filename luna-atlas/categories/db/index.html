Documented methods to start with

Public and SSAP methods from LG's documentation, none flagged dangerous. Each opens in the catalog with its full parameter table. Run them on a rooted TV or in Developer Mode.

batch publiccom.palm.db

Executes multiple database operations in one request.

params: operations

$ luna-send -n 1 -f luna://com.palm.db/batch '{}'
del publiccom.palm.db

Deletes JSON data objects.

params: ids, query, purge

$ luna-send -n 1 -f luna://com.palm.db/del '{}'
delKind publiccom.palm.db

Deletes a kind and ALL objects of that kind.

params: id

$ luna-send -n 1 -f luna://com.palm.db/delKind '{}'
find publiccom.palm.db

Returns objects matching the query.

params: query, count, watch

$ luna-send -n 1 -f luna://com.palm.db/find '{}'
get publiccom.palm.db

Retrieves objects by IDs (fastest retrieval).

params: ids

$ luna-send -n 1 -f luna://com.palm.db/get '{}'
merge publiccom.palm.db

Updates properties of existing objects.

params: objects, query, props

$ luna-send -n 1 -f luna://com.palm.db/merge '{}'
put publiccom.palm.db

Stores JSON objects of a kind.

params: objects

$ luna-send -n 1 -f luna://com.palm.db/put '{}'
putKind publiccom.palm.db

Registers a kind with the database.

params: id, owner, schema, sync, extends, indexes, revsets, private

$ luna-send -n 1 -f luna://com.palm.db/putKind '{}'
putPermissions publiccom.palm.db

Grants other apps/services access to the app DB8 data.

params: permissions

$ luna-send -n 1 -f luna://com.palm.db/putPermissions '{}'
reserveIds publiccom.palm.db

Reserves a block of object IDs.

params: count

$ luna-send -n 1 -f luna://com.palm.db/reserveIds '{}'
search publiccom.palm.db

Like find but supports the ? full-text operator.

params: query, watch

$ luna-send -n 1 -f luna://com.palm.db/search '{}'

batch publiccom.webos.service.db

The batch method enables apps to execute multiple database operations in one service request. It allows only the following database operations: put get del find (without a watch) m

params: operations

$ luna-send -n 1 -f luna://com.webos.service.db/batch '{}'
cancelSearch publiccom.webos.service.db

Stops the search operation mid-way. This method can be used when the search operation takes a long time to return results or required to search with another keyword without waiting

params: taskId

$ luna-send -n 1 -f luna://com.webos.service.db/cancelSearch '{}'
compact publiccom.webos.service.db

$ luna-send -n 1 -f luna://com.webos.service.db/compact '{}'
del publiccom.webos.service.db

The del method deletes JSON data objects from the database. Apps can specify the objects to be deleted by providing: a set of IDs to be deleted a DB8 query

params: ids, query, purge

$ luna-send -n 1 -f luna://com.webos.service.db/del '{}'
delKind publiccom.webos.service.db

The delKind method deletes a Kind from the database. Deleting a Kind deletes ALL data objects of that Kind.

params: id

$ luna-send -n 1 -f luna://com.webos.service.db/delKind '{}'
dump publiccom.webos.service.db

Backs up a database. The file created by the dump method typically contains JSON statements to recreate all of the Kinds and data of the database from which they have been dumped.

params: path, incDel

$ luna-send -n 1 -f luna://com.webos.service.db/dump '{}'
Before you run anything. Methods marked dangerous can change, reset or break things on the TV. Running one from here is exactly as safe as typing the same luna-send yourself. See dangerous.md.
