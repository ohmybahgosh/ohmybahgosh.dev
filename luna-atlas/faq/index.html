Luna Atlas FAQ.

luna-send and the catalog, answered.

What is luna-send?
The command-line tool every LG webOS TV ships to talk to the Luna Service Bus, the internal message bus every system service listens on: power, apps, inputs, picture and sound, Wi-Fi, notifications and hundreds more.
What do I need to run a command?
A rooted TV, or LG's Developer Mode, and a shell on the TV. Browsing the catalog needs nothing.
What do public, private and the other access levels mean?
Public methods are open to normal apps. Private ones are for LG's own apps and services, and need root or a privileged caller. Some are only reachable as root, and SSAP methods are the ones LG's remote-control API exposes.
Is it safe to run these?
Many calls change settings, inputs or power, and a few can reset the TV, wipe data or brick it. Those are flagged dangerous. Running one from the catalog is exactly as safe as typing the same luna-send yourself.
Where does the data come from?
LG's webOS TV and webOS OSE docs, the homebrew and remote-control community, and the service list introspected from a rooted TV. Each method says whether it's documented or inferred.
Is there a command-line version?
Yes, luna-atlas.sh in the GitHub repo can search, show and run methods over SSH, with tab completion. It's an early preview.
Can I browse by what a command does?
Yes: browse by category, or start from common luna-send examples.
