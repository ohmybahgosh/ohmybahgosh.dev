SSH Doctor FAQ.

Fixing SSH on a rooted LG TV from the TV itself, answered.

What's the default SSH login for a rooted LG TV?
User root, port 22, password alpine, once SSH is turned on in the Homebrew Channel. Adding your first key turns the alpine password off at the next boot.
Why does SSH say Connection refused?
The SSH server isn't running or listening on that port. Turn on SSH in the Homebrew Channel's settings and restart the TV, or use SSH Doctor's Turn SSH on now, which starts it without a restart.
I added a key and now the password doesn't work.
That's by design: the first key in authorized_keys turns alpine off at the next boot. If the key itself doesn't work, often because of Windows line endings or a key pasted on several lines, SSH Doctor's Fix my keys file or Go back to password login gets you back in.
How can it fix SSH if SSH is broken?
It's a TV app that runs as root through the Homebrew Channel, not over SSH, so it works with just the remote.
How does pairing a key work?
Choose Set up a key on the TV, scan the QR code or open the address on your computer or phone, enter the short code, and upload a public key or let the browser make one. The private key never leaves your device.
Can I set my own root password?
Yes, on the TV or from your phone. It's turned into a SHA-512 crypt hash first, so the password itself is never sent over the network or saved on the TV.
Can I move SSH off port 22?
Yes. The old port stays open alongside the new one until you've logged in on the new one, so a typo can't lock you out.
Does it change system files?
No. Settings live in the Homebrew Channel's folders, a backup is kept before every change, and Reset to Homebrew Channel defaults removes all of it.
