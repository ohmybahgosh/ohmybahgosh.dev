Entware FAQ.

Linux packages and a real shell on a rooted LG TV, answered.

What is Entware?
A package manager for embedded Linux devices, with over a thousand packages. On a rooted LG TV it gives you opkg, a bash shell and tools like htop, tmux, git and Python.
What do I need?
A rooted LG TV with the Homebrew Channel, an internet connection on the TV and about 50 MB free. SSH is only needed for the shell: the TV app doesn't need it.
Which TVs does it support?
webOS 23, 24 and 25 are the main targets, and webOS 4 and up should work. Both 64-bit and 32-bit kernels are supported.
Why 32-bit or 64-bit?
Every LG TV runs a 32-bit system, but Entware brings its own libraries, so only the kernel matters. A 64-bit kernel gets the faster aarch64 build, a 32-bit one armv7.
What are add-ons?
25 one-press setups, each with what it needs on webOS: tools like git and Python, and network services like Tailscale, Samba, File Browser, a DLNA media server, Transmission and Syncthing.
Can I manage it from my phone?
Yes. Add-ons > Manage from your phone shows a QR code that opens a dashboard on your phone, signed in, for add-ons and passwords.
Does it survive a reboot?
Yes. A boot script from the Homebrew Channel mounts it at every start.
Does the app phone home?
No. It only talks to GitHub, to check for and download its own updates.
