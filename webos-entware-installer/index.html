Entware
for rooted LG webOS TVs

A real Linux
toolbox, on your TV.

Entware brings hundreds of Linux command line packages to rooted LG webOS TVs through opkg, plus a bash shell and 25 one-press add-ons, from git, Python and htop to Tailscale, Samba file sharing and Syncthing. Search and install any package from the remote. Set it up from the TV app in the Homebrew Channel, no SSH needed, or with one line over SSH. It checks your TV first, picks the right build, survives reboots and uninstalls cleanly.

features

Careful by default.

Built so a TV you love never ends up half-installed.

Checks before it touches

Root, model, webOS version, kernel, Homebrew Channel, free space and the Entware server, all before anything changes.

64

Picks the right build

Recommends 64-bit aarch64 or 32-bit armv7 from your kernel, explains why, and test-runs it. If 64-bit can't run, it falls back.

Never half-installed

A fresh install that fails partway undoes everything. A failed repair keeps your packages.

Survives reboots

A Homebrew Channel boot script remounts /opt and starts services with the PATH they need, including ones you installed yourself, with a backup remount at SSH login.

doctor

Shows what's installed and says exactly what to fix. Ends with "Everything looks right."

$_

A shell worth living in

Optional bash with nano, colors, a neon prompt and handy aliases, plus a safe fallback to the stock shell if bash ever breaks. Your own .profile and .bashrc are backed up and restored.

Room to grow

New installs go on the TV's app storage, about 2.7 GB on a C2 against 720 MB of user data, and it keeps Entware through "Reset to initial settings". Where it lives.

#

Root's alone

Entware runs as root, so it's only used when its folder and everything on the way to what runs is owned by root and writable by no one else. Anything else is unmounted unused.

webOS helpers

toast, launch, close, apps, applog and tvshot talk to the TV through luna-send, with Tab completion for app IDs.

webos-entware addons

One press. Set up for webOS.

Some packages need extra setup before they work on a TV. Add-ons do it for you, from the app or the command line. There are 25: nano with syntax colors, locate, HTTPS certificates, git, Python, htop, tmux, ncdu, rsync, curl, jq, rclone, Vim, Midnight Commander, micro, network, archive and search tools, a login banner with a webOS wordmark and your TV's specs, and six network services. Each one can be added, finished or removed on its own.

It checks what's already there first. Packages already installed aren't downloaded again, and when webOS has its own copy of a command, like curl or python3, it says so and asks first.

$ webos-entware addons
$ webos-entware add git
$ webos-entware add banner
$ webos-entware remove python
webos-entware info samba

Network services. Locked down first.

Six add-ons run a service that starts with the TV. Entware's stock settings for some of them let anyone on your network in, so each one is set up before it first starts.

add-onwhat you getwhere
tailscaleReach the TV over SSH from anywhere on your tailnet, with no ports opened. The app shows a QR code of the sign-in linkssh root@<tailnet IP>
sambaShare /opt/files with Windows and Mac, SMB2 and up\\<TV IP>\TV, user tv
filebrowserUpload, download and manage /opt/files from a browser on your phone or computerhttp://<TV IP>:8090, user admin
minidlnaA DLNA media server: play videos, music and photos from /opt/files and USB drives on other TVs, consoles and VLC. DLNA has no login, and it only reads"LG TV (Entware)"
transmissionTorrents from a browser, saved to /opt/files/Downloadshttp://<TV IP>:9091, user tv
syncthingKeep a folder like /opt/files/Sync in sync with your phone and computershttp://<TV IP>:8384, user tv

A password made on the TV, 16 random letters and numbers, for anything with a login. Only root can read it, and adding the add-on again keeps it.

No guest access, and nothing starts with Entware's stock settings. If a setup doesn't finish, the service is stopped and kept from starting at boot.

One shared folder, /opt/files, with Downloads, Media and Sync, and USB drives in USB. Removing a service never deletes your files.

Checked first: a service won't start if something else on the TV has its port. Everything is plain http on your home network, so browsers show "Not secure", with no certificate warnings.

$ webos-entware add samba
$ webos-entware info samba            # address, user and password
$ webos-entware password samba        # a new random one
$ webos-entware password samba --ask  # or type your own

Open a service in Add-ons for its address and password, with a QR code for your phone, and New random password.

webos-entware web start

Manage it from your phone.

Add-ons > Manage from your phone shows a QR code. Scan it and your phone's browser opens a dashboard, signed in, like TiviBro's web editor. Add and remove add-ons, see each service's address and password with Show password and Copy password, and Change password: a random one, or type your own with Show and a checklist as you type. Symbols are fine.

A sign-in code on the TV, eight characters that can't be mistaken for each other across a room. Five wrong codes lock that phone out for a minute.

Home network and tailnet only. It stops after 30 minutes unused, or when you choose Stop on the TV, and it can't do more than the TV app can.

$ webos-entware web start   # prints the address and code
$ webos-entware web stop

ssh install

Prefer SSH?

The TV app is the easiest way in, but the same installer works over SSH. It needs a rooted TV with the Homebrew Channel, SSH turned on (keep telnet on too as a way back in), an internet connection and about 50 MB free.

$ wget -O /tmp/webos-entware-installer.sh https://raw.githubusercontent.com/ohmybahgosh/WEBOS-ENTWARE-INSTALLER/main/webos-entware-installer.sh
$ sh /tmp/webos-entware-installer.sh

Pick 1) Install or repair Entware, confirm the recommended build, then disconnect and SSH in again for bash.

$ wget -O - https://raw.githubusercontent.com/ohmybahgosh/WEBOS-ENTWARE-INSTALLER/main/webos-entware-installer.sh | sh -s -- install

Still asks its questions in your SSH session. Add -y to take the recommended build.

$ sh /tmp/webos-entware-installer.sh install     # install or repair
$ sh /tmp/webos-entware-installer.sh doctor      # check the TV
$ sh /tmp/webos-entware-installer.sh uninstall   # remove everything

Where Entware lives.

Since 2.9, new installs go on app storage. Installs on user data move over with a checked move on their next repair, or whenever you choose.

app storage (default)user data
Folder/mnt/lg/appstore/entware/mnt/lg/user/opt
Size on a C2about 2.7 GBabout 720 MB
Shared withinstalled appswebOS's own settings, caches and databases
Firmware updatekeptkept
"Reset to initial settings"keptdeleted
Factory resetdeleteddeleted

A move stops Entware's services, copies everything into a fresh folder, checks the copy, switches /opt over and checks it's that very copy, and only then removes the old one. If anything fails before the switch, Entware stays where it was. It took 28 seconds for 25 MB on a C2.

$ webos-entware move appstore   # move to app storage
$ webos-entware move user       # or keep it on user data
$ sh webos-entware-installer.sh install --location=user

In the TV app, Check and repair moves an older install, and Move to app storage does it on its own. Choosing a place sticks: repairs won't move it again.

ent

ent is a separate helper for searching, installing and checking packages, with Tab completion for package names. ent search shows each package as its own short block, so it's easy to read even over SSH from a phone. faq

Questions.

Was this written by AI?
Recent versions are written with AI coding agents (Claude), directed, reviewed and tested by me. A test suite runs install, repair, reboots, add-ons and uninstall in a sandbox under busybox sh and dash, and the installer test-runs each build on your TV before keeping it. How these are built.
Why 32-bit or 64-bit?
Every LG TV runs a 32-bit system, but Entware brings its own libraries, so only the kernel matters. A 64-bit kernel runs the faster aarch64 build (one owner measured about 19% on a G4). A 32-bit kernel needs armv7.
Where does it download from?
Entware and its packages come only from Entware's official server, using the same files as Entware's own generic.sh installer. App updates come from this project's GitHub releases and are checked against their SHA256SUMS. The login banner add-on downloads neofetch 7.1.0 from GitHub and only uses it if it matches that release's checksum.
I installed Entware before 2.9. Do I need to do anything?
No. Your next repair (Check and repair in the app, or webos-entware install) moves it from user data to app storage with a checked move, keeping your packages. Over SSH it asks first. To keep it on user data, say no, or run webos-entware move user.
Does the app phone home?
No. It only talks to GitHub: it reads the latest release number to say when an update is out, and downloads that release when you choose Update.
SSH closes right after login?
Get a plain shell with ssh -t root@TV_IP sh or telnet, run rm /home/root/.profile, then webos-entware install to repair.
How is it tested?
250+ tests run install, repair, reboots, add-ons, moves, updates and uninstall inside a private mount namespace with fake wget and opkg, under busybox sh and dash. CI also builds the TV app and drives it with the remote's keys in a headless browser. Changes are tried on a real TV, an LG C2 (OLED65C2PUA) with webOS 25 (10.3.1), before release.
