FW Block FAQ.

Blocking LG firmware updates on a rooted TV, answered.

What does FW Block block?
webOS's update check and Automatic software update, an update webOS already found, all seven LG update servers, the address the updater reaches with no name (156.147.69.32), LG Remote Support, phone app updates, and a download that starts anyway. It checks all of it every 10 minutes and at every start.
Isn't the Homebrew Channel's Block system updates enough?
It covers four servers. The updater also knows nsu.lge.com, snu-dev.lge.com and ngfts.lge.com, reaches an address with no name, and checks on its own, and none of that touches Remote Support or phone apps. FW Block keeps the Homebrew Channel's block and adds the rest.
Will casting and the phone remote still work?
Yes. Only the update service's update calls are taken away from paired phones. Every other phone call is unchanged, checked with LG's own gateway code on webOS 25 and 26.
I use LG-USB-2-ETH0. Do I need FW Block?
No. Newer LG-USB-2-ETH0 versions block everything FW Block does. With both installed, FW Block shows that LG-USB-2-ETH0 keeps each block and takes over only if that one is turned off.
Does turning FW Block off turn the others off?
No. It removes only what it added. LG-USB-2-ETH0's and the Homebrew Channel's blocks stay as they were.
What are the backups for?
Before it turns on, restores or updates, it saves webOS's update settings, its own switches, /etc/hosts, the phone gateway's file and the firewall's rules. Backups in the app puts one back.
How does it update?
The app checks GitHub when it opens, and Updates installs a new version through the Homebrew Channel, only if the release is signed with the project's key.
What happens if I uninstall it?
It notices within about 30 seconds and undoes everything it added, then removes its startup hook and folder.
Was FW Block written by AI?
Partly, and openly. It's written with AI coding agents (Claude), directed, reviewed and tested by OhMyBahGosh. Nothing ships until it runs on a real TV, 58 tests run on every push, and releases are signed. How these are built.
