FW Block
for rooted LG webOS TVs

Block LG firmware updates.
Keep your root.

One firmware update can take root off your LG TV for good, along with everything you installed through the Homebrew Channel. LG's current firmware patches the known ways in. FW Block closes every route to an update we found by running LG's own updater in a sandbox and reading nine firmwares, from 2018 models to webOS 26: the update check, all seven update servers, the address with no name, LG Remote Support, phone apps, and a download that starts anyway. It keeps them closed, backs itself up before every change, and shows exactly what's blocked and who blocks it.

Every way in, closed.

The Homebrew Channel's Block system updates covers four servers. FW Block keeps it, and closes the rest.

01

The update check, off

webOS's hidden softwareUpdateEnable and the visible Automatic software update. The updater doesn't even ask, from the moment the TV starts.

02

Found updates, gone

An update webOS already found or downloaded is deleted before it can install, and a waiting prompt goes away.

03

Seven servers, nowhere

snu, su, su-ssl, su-dev, snu-dev, nsu and ngfts.lge.com in /etc/hosts, including the three the Homebrew Channel misses.

04

The address with no name

With its "network" server, the updater goes straight to 156.147.69.32. A firewall rule in a chain of its own drops it.

05

LG Remote Support

A support session can hand the updater a download directly. Its servers and addresses are blocked, with a switch for when LG support needs in.

06

Phone apps

A paired phone app can push an update straight from the phone. FW Block takes away only the update calls: casting, the phone remote and ThinQ keep working.

07

A download that starts anyway, stopped

From a support session or the antenna, cancelled within 30 seconds with a notice on the TV. An install already running is never interrupted, and USB updates you start yourself are left alone. All seven are checked every 10 minutes and at every start, and anything undone is put back.

Automatic backups

Before it turns on, restores or updates, FW Block saves webOS's update settings, its own switches, /etc/hosts, the phone gateway's file and the firewall's rules. Backups lists the newest 10 and puts one back.

↓

Signed updates from the app

Each time it opens, it checks GitHub for a newer release. A newer one shows at the top of the More tab, and Update installs it through the Homebrew Channel, only if it's signed with the project's release key, and the block stays on the whole time.

faq

Questions.

Does turning FW Block off turn off LG-USB-2-ETH0's block, or the Homebrew Channel's?
No. FW Block only removes what it added itself. Their settings, hosts lines and firewall rules stay exactly as they were.
I already use LG-USB-2-ETH0's Block updates harder. Do I need this?
No. Newer LG-USB-2-ETH0 versions block everything FW Block does. Install both and FW Block shows that LG-USB-2-ETH0 keeps each block, stays out of its way, and takes over if that block is ever turned off.
Will casting and the phone remote still work?
Yes. The phone block only takes away the update service's update calls. Every other phone call stays the same, which was checked with LG's own gateway code on webOS 25 and 26.
Why does the phone block say "from the next TV start"?
The TV's phone connection reads which calls it offers when it starts, and FW Block never restarts it. Restart the TV once and it holds from then on.
Can it undo an update that already installed?
No. Nothing can undo a firmware update from the TV, so block updates before LG gets the chance.
Does it block app updates?
No. The LG Content Store and app updates are left alone. Only firmware updates are blocked.
Was this written by AI?
Partly, and openly. It's written with AI coding agents (Claude), directed, reviewed and tested by me. Nothing ships until it's run on a real TV (an LG C2 on webOS 25), and the fixes that mattered most came from that testing: luna-send quietly eating the script's input, the TV's fonts missing a symbol, and LG-USB-2-ETH0's new phone block looking like a gap until the next start. The blocks themselves come from running LG's own updater in a sandbox and reading nine firmwares. 58 tests run on every push, releases are signed, and no system partition is written.
