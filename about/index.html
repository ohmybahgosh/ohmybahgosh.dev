~/about

whoami.

Data engineer. Pentester. Tinkerer. Builder of things LG forgot to ship.

I'm OhMyBahGosh. I like hoarding data, finding things and solving problems.

By day I'm a data engineer, and the Swiss Army knife of the team. On any given day that means data pipelines, Google Ads, full-stack Shopify development, automation or AI tooling, usually more than one before lunch. I've been building for the web for more than 17 years, with a background in security and software development.

Off the clock I'm into penetration testing and network security: finding the weak spot before someone else does. I also automate anything that holds still long enough.

Yes, I vibe code. Not blindly.

And yes, I've been vibe coding lately. Not the blind kind, where you paste whatever a model hands you and hope. AI lets one person build in a weekend what used to take a team a month, and that's a real shift worth using. But speed without scrutiny is how you ship bugs and security holes at scale. So everything here gets the same treatment as hand-written code: I design it first, read every line, test it on real hardware, and audit it the way someone who breaks things for fun would. The AI writes faster. The judgment is still mine. Here's what that looks like for each project.

That's how my TV ended up running a homebrew IPTV player I wrote because the one I wanted didn't exist on webOS. Its Ethernet port is a USB adapter pretending to be the built-in one. It has a full Linux toolbox installed, and a remote dedicated server keeps the media flowing.

I've also put out a few things people found useful along the way, like RockYou2021.txt, a large password-auditing wordlist used for security testing. There's also a pile of yt-dlp scripts that were cutting-edge back when they worked. They're now historical artifacts, preserved for science. Run them at your own nostalgia.

Everything I publish is free and open source, written in plain language, and built to check before it touches anything and to clean up after itself. If something breaks, tell me. That's how it gets better. Unless it's the yt-dlp scripts. Those are already broken.
