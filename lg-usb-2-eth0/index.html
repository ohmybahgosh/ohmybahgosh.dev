~/lg-usb-2-eth0

Your TV's
fast lane is eth0.

LG TVs ship with a 100 Mbit/s wired port. A USB gigabit adapter is two to three times faster, even on a USB 2.0 port like the one on a 2022 C2, but webOS calls it eth1 and ignores it. LG-USB-2-ETH0 makes the adapter the TV's eth0, safely and at every boot. Use the TV app from the Homebrew Channel, no SSH needed, or the same script over SSH.

what it fixes

Three problems, one rename.

▶

Streaming apps fail

Apps like Paramount+ refuse to play over eth1. The adapter becomes eth0, so they play.

⚙

"Not Connected"

webOS settings show no wired connection while the adapter works. Interface names now match what webOS expects.

⇡

100 Mbit/s ceiling

High-bitrate remuxes, Plex and Moonlight stutter on the built-in port. The adapter does 250 to 330 Mbit/s.

real speeds

Not gigabit. Still 3x.

The TV's USB controller and CPU are the limit, so don't expect gigabit. But two to three times the built-in port is plenty for 4K remuxes.

Measured by DonZoomik (webos-r8152), lgwebos.com users and on the author's C2.

how it works

One hook. Nothing else touched.

At boot the Homebrew Channel runs everything in /var/lib/webosbrew/init.d. LG-USB-2-ETH0 adds one hook there, a link to the script, and keeps its settings in /var/lib/webosbrew/lg-usb-2-eth0.conf, so updates never lose them. It only renames network interfaces. No system files or network settings are touched, so a reboot without the hook always starts clean.

Undo everything: Turn everything off in the TV app, or sh LG-USB-2-ETH0.sh uninstall --now

Returns at once

Starts in the background so other hooks and the failsafe timer aren't held up.

Waits for a real adapter

Only wired Ethernet on USB counts. Wi-Fi, phones and modems are skipped. No adapter, no changes.

Optional faster driver

With --module, moves the adapter from generic cdc_ncm to a better driver, with one try per boot and an automatic fallback.

Swaps the names

Built-in eth0 becomes eth2, the adapter becomes eth0. Interrupted renames retry, and failures roll back.

Follows hotplug

With --watch, plug the adapter in or out any time and eth0 follows it.

Survives standby

Standby resets the TV's USB ports and drops the adapter back to cdc_ncm. With --module, the hook moves it to the faster driver again. The check costs next to nothing.

ssh quick start

Prefer SSH?

The TV app is the easiest way in. This is the same thing without it. You need a rooted LG TV with the Homebrew Channel, SSH as root, and a Wi-Fi connection while you set this up, since renaming takes the wired ports down for a moment.

$ cd /tmp
# download the latest release and its checksum
$ curl -fsSLO https://github.com/ohmybahgosh/LG-USB-2-ETH0/releases/latest/download/LG-USB-2-ETH0.sh
$ curl -fsSLO https://github.com/ohmybahgosh/LG-USB-2-ETH0/releases/latest/download/SHA256SUMS
$ sha256sum -c SHA256SUMS
# read-only look at the TV first
$ sh LG-USB-2-ETH0.sh status
# install the boot hook (asks before it writes), then switch now
$ sh LG-USB-2-ETH0.sh install
$ sh LG-USB-2-ETH0.sh apply

No curl? Use wget the same way. On a TLS error, download on your computer and copy over with scp.

compatibility

The chip matters more than the brand.

What decides whether it works is whether your TV's kernel has a driver for your adapter's chip. Run status before buying: it lists the USB network drivers your kernel has.

RTL

Realtek 8153 / 8156

The most common gigabit and 2.5G chips. Newer kernels may only offer generic cdc_ncm, which works but is slower. get-driver fixes that on supported kernels.

AX

ASIX AX88179

Works out of the box on many older TVs. One report of the newer AX88179A not being detected on webOS 25.

USB

USB 2.0 is fine

Many TVs, like the 2022 C2, only have USB 2.0 ports. That tops out around 300 Mbit/s: still about 3x the built-in port and faster than Wi-Fi. Use USB 3.0 if your TV has it, and a powered hub for fussy adapters.

faq

Questions.

Was this written by AI?
Partly, and openly. I wrote v1 by hand. From v2.0 on it's written with AI coding agents (Claude), directed, reviewed and tested by me. Nothing ships until it's run on a real TV (an LG C2 on webOS 25), and the fixes that mattered most came from that testing: standby putting the adapter back on the slow driver, and webOS quietly using Wi-Fi instead of the adapter. 60+ tests run on every push, downloads are checked by SHA-256, and no system files are touched. The driver modules come from DonZoomik and mbenitez343, not from AI. How these are built.
Does it survive a firmware update?
The hook lives in the Homebrew Channel's folder, so it stays as long as root does. If an update removes root, the TV just goes back to the built-in port.
Does it change my network settings?
No. webOS still sets up the wired connection itself. The script only changes which device is called eth0.
Lost SSH while switching?
The switch still finishes on the TV. Reconnect over Wi-Fi. The adapter has its own MAC, so your router may hand out a new IP; a DHCP reservation keeps it steady.
Can I use two adapters?
Yes. Pin the one you want with --mac. Without it, the first adapter with a cable in wins.
Thanks to DonZoomik for webos-r8152, the Realtek driver build and benchmarks that get-driver and --module are built on.
