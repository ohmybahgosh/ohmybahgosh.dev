Install guide.

Everything you need to get the apps onto an LG TV: whether yours can be rooted, the Homebrew Channel, the repository, and which app works on which TV.

1. Check whether your TV can be rooted

Three of the four TV apps need root, because they change things a normal app can't: which network port the TV uses, Linux packages on its storage, and its SSH server. Whether a TV can be rooted depends on its exact firmware version, so look it up first at cani.rootmy.tv.

webOS 26 and current firmware. LG has been patching the holes rooting tools use. Per the EPK archive's rooting guide, webOS 26 firmware released after October 10, 2026 can't be rooted, and once a TV is on patched firmware it can't be rooted again. On a rooted TV, keep updates off: the Homebrew Channel's Block system updates, and LG-USB-2-ETH0's Block updates harder for what that misses.

The common rooting tools are RootMyTV, faultmanager-autoroot (webOS 4.0 to 4.5 and others), crashd and DejaVuln. The webosbrew rooting page lists which one fits which firmware.

2. The Homebrew Channel

Every rooting tool above installs the webOS Homebrew Channel, the open-source app store for rooted LG TVs. It runs apps as root, turns SSH and telnet on, blocks system updates, and installs apps from repositories. If it's on your home screen, you're ready for step 3.

3. Add the ohmybahgosh.dev repository

One repository gives you all four TV apps, and each new release shows up as an update.

https://ohmybahgosh.dev/repo

Open the Homebrew Channel's settings

Open the Homebrew Channel and select the gear icon at the top right.

Add the repository

Scroll to Repositories, choose Add repository, enter https://ohmybahgosh.dev/repo and confirm.

Install the apps

Go back to the app list. TiviBro, LG-USB-2-ETH0, Entware and SSH Doctor are there: install the ones you want.

More detail, and how to remove a repository, in How to add a repository to the Homebrew Channel.

No root?

LG's own Developer Mode can install apps on any webOS TV, without root. TiviBro works that way: its install guide on tivibro.app covers it. Developer Mode sessions expire and need renewing, and the three tools that change the system still need root.

FAQ

Do I need a rooted TV?
For LG-USB-2-ETH0, Entware and SSH Doctor, yes: they change things only root can. TiviBro also runs in LG's Developer Mode without root, and Luna Atlas's catalog is a web page anyone can browse. Running luna-send commands needs root or Developer Mode.
Can my TV still be rooted?
It depends on the exact firmware, not just the model. Check it at cani.rootmy.tv. As of November 2026, webOS 26 firmware released after October 10, 2026 can't be rooted, and a TV on patched firmware can't be rooted again, so keep firmware updates off on a rooted TV.
What is the Homebrew Channel?
The open-source app store for rooted LG TVs, from the webosbrew project. The rooting tools install it, it runs apps as root, and it can add repositories like ohmybahgosh.dev/repo so apps show up and update from the TV.
Will these apps void anything or change system files?
None of them writes to the TV's system partitions. They keep their files in the Homebrew Channel's folders or on app storage, and each one has a clean uninstall. Rooting itself is your choice and your risk, as with any homebrew.
How do updates work?
Once the repository is added, new versions show up in the Homebrew Channel as an update for each app. The site rebuilds the repository from each project's GitHub releases, so an update is usually listed within minutes of a release.
